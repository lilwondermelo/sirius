# Проект "Веб-конструктор интернет-магазина"

## 1. Обзор проекта

Судя по структуре файлов, этот проект представляет собой веб-приложение для создания и управления простым интернет-магазином или каталогом товаров. Название корневой папки `constructor` предполагает, что это может быть либо платформа для "сборки" сайтов, либо сам сайт, созданный таким конструктором.

Основной функционал построен на классическом стеке **PHP + JavaScript (jQuery)**, что типично для многих веб-проектов.

## 2. Ключевые особенности

*   **Клиент-серверная архитектура**: Четкое разделение на frontend (папки `js`, `css`, `media`) и backend (папка `server`).
*   **Динамический каталог товаров**: Товары и их категории, по-видимому, загружаются динамически.
*   **Хранение данных в `.ini` файлах**: Вместо традиционной базы данных (например, MySQL), для хранения категорий товаров (`одежда.ini`, `электроника.ini` и т.д.) используются конфигурационные `.ini` файлы. Это упрощенный подход к хранению структурированных данных.
*   **Корзина покупок**: Наличие файлов `cart.js` и иконки `cart.svg` прямо указывает на реализацию функционала корзины.
*   **AJAX-взаимодействие**: Файлы `api.js` и `_ajaxListener.class.php` свидетельствуют о том, что frontend общается с backend асинхronно, без перезагрузки страницы, для получения данных или добавления товаров в корзину.

## 3. Технологический стек

*   **Backend**:
    *   **PHP**: Основной язык серверной логики. Классы в папке `server/core` (`_dataSource.class.php`, `_dataRowUpdater.class.php`) говорят об объектно-ориентированном подходе к разработке.
*   **Frontend**:
    *   **HTML/CSS**: Стандартная разметка и стилизация.
    *   **JavaScript**: Основной язык для интерактивности на стороне клиента.
    *   **jQuery**: Используется для упрощения DOM-манипуляций и AJAX-запросов.
*   **Данные**:
    *   **INI-файлы**: Для хранения информации о категориях товаров.
    *   **JSON**: Файл `settings.json` может использоваться для глобальных настроек приложения.

## 4. Структура проекта

-   `index.php`: Главная точка входа в приложение.
-   `/server/`: Содержит PHP-классы для обработки логики на стороне сервера.
    -   `app.class.php`: Вероятно, главный класс приложения.
    -   `/core/`: Ядро бэкенда, отвечающее за подключение к данным, обработку AJAX-запросов и обновление информации.
-   `/js/`: Содержит JavaScript-файлы.
    -   `main.js`: Основной скрипт, инициализирующий логику.
    -   `api.js`: Для отправки запросов на сервер.
    -   `cart.js`: Логика работы корзины.
    -   `render.js`: Отвечает за отрисовку элементов на странице.
-   `/css/`: Стили оформления.
-   `/files/`: Хранилище `.ini` файлов с данными о категориях.
-   `/media/`: Медиафайлы (шрифты, иконки, изображения товаров).

## 5. Как запустить

Проект предназначен для работы на веб-сервере с поддержкой PHP (например, Apache или Nginx в составе OSPanel, судя по пути к проекту).

1.  Разместить файлы проекта в корневой директории локального веб-сервера.
2.  Открыть в браузере адрес, соответствующий этой директории (например, `http://constructor.local`).

## 6. Возможные улучшения

*   **Переход на базу данных**: Миграция данных из `.ini` файлов в реляционную базу данных (MySQL, PostgreSQL) для повышения производительности и масштабируемости.
*   **Рефакторинг Frontend**: Переход с jQuery на современный JavaScript-фреймворк (например, Vue.js или React) для создания более отзывчивого и структурированного пользовательского интерфейса.
*   **Безопасность**: Внедрение защиты от основных веб-уязвимостей (XSS, CSRF, SQL-инъекции после перехода на БД).
*   **Система администрирования**: Создание панели администратора для удобного управления товарами и категориями без прямого редактирования файлов.
