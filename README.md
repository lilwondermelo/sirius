# Проект "Веб-конструктор интернет-магазина "

## 1. Обзор проекта

Этот проект представляет собой веб-приложение для создания и управления простым интернет-магазином или каталогом товаров. Он построен на классическом стеке **PHP + JavaScript (jQuery)** и использует базу данных MySQL для хранения информации.

## 2. Ключевые особенности

*   **Клиент-серверная архитектура**: Четкое разделение на frontend (папки `js`, `css`, `media`) и backend (папка `server`).
*   **Работа с базой данных**: Проект использует MySQL для хранения данных о товарах, категориях и ценах, что обеспечивает централизованное управление.
*   **Динамический контент**: Меню категорий и товары загружаются динамически из базы данных без перезагрузки страницы.
*   **Корзина покупок**: Реализован базовый функционал корзины.
*   **AJAX-взаимодействие**: Frontend асинхронно общается с backend для получения данных, что делает интерфейс более отзывчивым.

## 3. Технологический стек

*   **Backend**:
    *   **PHP**: Основной язык серверной логики с использованием объектно-ориентированного подхода.
    *   **MySQL**: Система управления базами данных.
*   **Frontend**:
    *   **HTML/CSS**: Стандартная разметка и стилизация.
    *   **JavaScript**: Основной язык для интерактивности на стороне клиента.
    *   **jQuery**: Используется для упрощения DOM-манипуляций и AJAX-запросов.
*   **Данные**:
    *   **JSON**: Файл `settings.json` может использоваться для глобальных настроек приложения.

## 4. Структура проекта

-   `index.php`: Главная точка входа в приложение.
-   `/server/`: Содержит PHP-классы для обработки логики на стороне сервера.
-   `/js/`: Содержит JavaScript-файлы для реализации логики на стороне клиента.
-   `/css/`: Стили оформления.
-   `/media/`: Медиафайлы (шрифты, иконки, изображения).
-   `/migration/`: Содержит SQL-скрипты для создания (`migration.sql`) и наполнения (`seed.sql`) базы данных.
-   `/logs/`: Логи работы и сессий разработки.

## 5. Как запустить

Проект предназначен для работы на веб-сервере с поддержкой PHP и MySQL (например, OSPanel).

1.  Создайте пустую базу данных в MySQL.
2.  Импортируйте в нее структуру таблиц из файла `migration/migration.sql`.
3.  Заполните таблицы начальными данными, выполнив скрипт `migration/seed.sql`.
4.  Разместите файлы проекта в корневой директории локального веб-сервера.
5.  Откройте в браузере адрес, соответствующий этой директории (например, `http://constructor.local`).

## 6. Возможные улучшения

*   **Рефакторинг Frontend**: Переход с jQuery на современный JavaScript-фреймворк (например, Vue.js или React) для создания более структурированного и масштабируемого интерфейса.
*   **Безопасность**: Внедрение защиты от основных веб-уязвимостей (XSS, CSRF, SQL-инъекции).
*   **Система администрирования**: Создание панели администратора для удобного управления товарами и категориями.

## 7. Внешний API

Для интеграции с внешними системами реализовано два основных эндпоинта.

### Эндпоинт

Все внешние запросы должны отправляться методом `POST` на:
`https://ваш-домен.ru/server/core/_ajaxListener.class.php`

Запрос должен быть отправлен в формате `x-www-form-urlencoded` или `form-data` и содержать поля `classFile: app.class` и `class: App`, а также `method` и `data`, специфичные для каждого шага.

---

### Шаг 1: Сверка товаров (`handleExternalApi`)

Этот метод используется для проверки наличия товаров поставщика в базе данных. Он возвращает списки совпавших и ненайденных товаров.

-   `method`: `handleExternalApi`
-   `data`: JSON-строка со следующей структурой:
    -   `supplierTin` (string, обязательное): ИНН поставщика.
    -   `skus` (array, опционально): Массив артикулов поставщика.
    -   `names` (array, опционально): Массив наименований товаров у поставщика.

**Пример использования (cURL):**

```bash
curl -X POST https://ваш-домен.ru/server/core/_ajaxListener.class.php \
-d "classFile=app.class" \
-d "class=App" \
-d "method=handleExternalApi" \
-d 'data={"supplierTin":"1234567890","skus":["SKU001","SKU002"]}'
```

---

### Шаг 2: Синхронизация товаров (`handleExternalApiProductSync`)

Этот метод синхронизирует список товаров: создает новые и **обновляет цены для существующих**.

-   `method`: `handleExternalApiProductSync`
-   `data`: JSON-строка со следующей структурой:
    -   `supplierTin` (string, обязательное): ИНН поставщика.
    -   `products` (array, обязательное): Массив объектов товаров.

**Структура объекта товара в массиве `products`:**

-   `Наш Артикул` (string, обязательное): Уникальный артикул товара в вашей системе.
-   `Артикул` (string, опционально): Артикул товара у поставщика.
-   `Наименование товара` (string, опционально): Наименование товара у поставщика.
-   `Новая цена` (number, опционально): Новая цена для товара. Если она отличается от последней зафиксированной цены, будет создана новая запись о цене.

**Пример использования (cURL):**

```bash
curl -X POST https://ваш-домен.ru/server/core/_ajaxListener.class.php \
-d "classFile=app.class" \
-d "class=App" \
-d "method=handleExternalApiProductSync" \
-d 'data={"supplierTin":"1234567890","products":[{"Наш Артикул":"V001","Артикул":"SKU001","Наименование товара":"Товар 1","Новая цена":150.75},{"Наш Артикул":"V002","Артикул":"SKU002","Наименование товара":"Товар 2","Новая цена":349.99}]}'
```
